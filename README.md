Use different font weights to create a strong visual hierarchy:

Medium for supporting text

SemiBold for buttons and subheadings

Primary Blue: #1565D8

Dark Blue: #0B1F3A

Light Blue: #EAF3FF

White: #FFFFFF

Light Gray: #F7F9FC

Keep the overall design clean with plenty of white space.

Avoid overly colorful gradients or unnecessary visual effects.
